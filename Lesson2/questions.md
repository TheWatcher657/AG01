# Mission: Wake Up AURA

You have joined **AURA**, a small AI research lab.

AURA is an experimental AI agent that has just been switched on, but its memory system is still empty.

Your first task is to help AURA learn basic information about its world. Each challenge unlocks the next part of the system.

---

## Mission 1: Wake Up AURA

AURA's first task is simply to introduce itself.

Write a Python program that prints:

```text
Hello, I am AURA.
I am ready to learn.
```

**Concept:** `print()`

---

## Mission 2: Give AURA a Name

AURA needs to remember the name of its new operator.

Create a variable called `operator_name` and store your name in it.

Then print:

```text
My operator is <your name>
```

**Concept:** Variables and strings

---

## Mission 3: Check AURA's Battery

AURA reports that its battery is currently at **85%**.

Store the battery percentage in a variable called `battery` and print:

```text
AURA battery: 85
```

Now change the battery to `90` and print it again.

**Question:** What value will Python print the second time?

**Concept:** Variables and reassignment

---

## Mission 4: Decode the Message

AURA receives a mysterious message:

```python
code = "activate"
```

Your job is to help AURA inspect the message.

Write Python code to:

1. Print the message in uppercase.
2. Print the number of characters in the message.

**Concept:** Strings, `.upper()`, and `len()`

---

## Mission 5: Enter the Command

AURA asks for the operator's access level.

The user enters a number, but Python receives it as text.

Complete this program so that if the user enters `7`, AURA prints:

```text
Access level: 8
```

Starter code:

```python
level = input("Enter your access level: ")

# Write your code here
```

**Concept:** `input()` and type conversion with `int()`

---

## Mission Complete

If you completed all five missions, you have successfully helped AURA:

* Display information
* Store information
* Update information
* Work with text
* Accept and convert user input

These are the first building blocks AURA will need before it can become a more capable AI agent.
